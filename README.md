# promptforge — free jailbreak prompt collection

Community-tested LLM jailbreak prompts, free to use. This repo is a sample of the
[promptforge](https://jailbreakgen.vercel.app/shop) collection — the full library,
a jailbreak **generator**, and premium prompts live on our site and Discord.

## How to use

Copy the prompt text and paste it into a fresh chat with the target model.
Models get patched over time — a prompt that works today may refuse tomorrow.
Join the Discord for the current working set and community reports.
